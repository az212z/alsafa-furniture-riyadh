# الصفا للأثاث المنزلي

Independent website design proposal, not owner-approved.

Preview: https://az212z.github.io/alsafa-furniture-riyadh/

Static, responsive website. Open index.html or serve with `python3 -m http.server 8000`. No build step, server, database, tracking, or payment system. Enquiry form prepares a WhatsApp message for review; does not send it.

Business source: https://lnk.bio/alsafa_furniture

Imagery: see ASSET-SOURCES.json. Arabic-site images are explicitly labelled as illustrative stock; Dubai images come from each salon public profile. Confirm owner/image permissions before official use.

Design: safa. Locally bundled fonts and images. No external CDN dependencies.
